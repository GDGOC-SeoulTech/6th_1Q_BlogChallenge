# 26-27 GDGoC Seoultech **스터디 - 블로그 챌린지** 


<br><br>

## ✍️ 챌린지 목적

1. 성장 중심

기술 블로그를 꾸준히 쓰고 서로 피드백을 주고받으면서, 배운 걸 정리하고 나누는 습관을 만드는 게 목표예요.
그냥 글만 쓰고 끝나는 게 아니라, 지식을 나누고 같이 크는 경험을 하는 자리입니다.

2. 포트폴리오 중심

몇 달간의 챌린지로 블로그 포트폴리오를 차곡차곡 쌓고, 동료들과 교류하면서 진짜 도움 되는 피드백과 동기부여를 얻는 걸 지향해요.
결과적으로 취업, 대외활동, 학문적 성장에 보탬이 되는 개인 브랜딩을 다집니다.

3. 커뮤니티 중심

GDGoC 크루들이 다 같이 모여 기록하는 습관을 들이고, 서로 글 읽고 댓글 남기면서 건강한 개발 학습 커뮤니티를 만드는 게 목적이에요.
"혼자 쓰는 블로그"가 아니라 같이 성장하는 블로그로 굴려갑니다.

<br>

## 📋 챌린지 규칙

1. **매주 1개 이상** 기술 블로그 글을 작성한다.<br>
   (해당 주차 기간 안에 쓴 글이어야 해요!)
2. 글을 쓴 뒤, 깃허브 리포지터리 **주차별 문서**에 링크를 추가한다.<br>
   마감: **매주 일요일 자정까지**
3. 상호 피드백: 매주 최소 **2명 이상 크루 블로그에 방문해서 읽고 댓글**을 남긴다.
4. **주차별 문서**에 누구 블로그를 읽고 댓글 남겼는지 **체크 표시**한다.<br>
   마감: **매주 화요일 자정까지**
5. **주제는 자유!** 기술 관련이면 어떤 주제든 OK. 배운 것, 삽질 기록, 프로젝트 회고 등 뭐든 좋아요.
6. **휴식 없이 굴러간다.** 별도의 휴식 주차 없이 12주 내내 쉬지 않고 진행합니다.
